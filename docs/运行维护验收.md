# 四项运行完善的人工验收

这次完善：内网免认证调用、普通任务流量限制、记录与日志清理、控制组件故障后的自动恢复。不增加管理后台或外部数据库。

## 1. 正常启动与免认证调用

```bash
cd /Users/wx/LazyX/sandbox_smokescreen
docker compose up --build -d
docker compose ps
python3 scripts/demo.py python
python3 scripts/demo.py deps-python
```

等待 `healthy`。Python 样例应返回计算值 5，依赖样例应成功；均不需要证书、Token 或执行许可。报告和产物仍保存在相邻的 `sandbox_smokescreen_outputs/manual/`。

确认默认模式：

```bash
docker compose exec -T sandbox .venv/bin/python -B - <<'PY'
from sandbox_model.client import connect
from sandbox_model.proto.sandbox_pb2 import Empty
channel, stub = connect()
print(stub.Ready(Empty(), timeout=3))
channel.close()
PY
```

应看到 `ready: true`、`mode: "independent"`。默认不启动合成 DNS、源站、镜像仓库或模拟连接器。`web`、`gateway` 两个人工样例需要测试模式，其他样例可以直接运行。

默认只发布到本机。需要另一台内网机器访问时，设置 `SANDBOX_BIND_IP` 为服务器实际内网 IP；客户端调用 `connect("内网IP:18443")`。接口不区分调用者，能访问端口的调用方都能查询和取消任务。

## 2. 一条命令验证四项功能

```bash
python3 scripts/run.py --operations
```

此命令会暂时启用合成测试模式并故意停止或挂起服务组件，期间不要提交其他任务。完成后恢复默认正常模式，再实际执行计算与公开 HTTPS 访问，确认服务可用。

应看到这些检查通过：

| 检查 | 验证什么 |
|---|---|
| 免认证执行 | 无客户端证书、无执行许可仍可提交和查询 |
| 上传、下载超限 | 多次 HTTPS 连接共享任务额度，捕获网络异常也不能绕过；返回对应 `NETWORK_*_LIMIT` |
| 日志轮转 | 超长单行也不能突破单文件 1 MiB、两份合计 2 MiB |
| 记录过期与去重 | 过期合成记录被删除，近期任务重复提交仍返回原结果 |
| 六种故障 | 分别强制结束、挂起管理服务、OpenSandbox、回收进程；自动恢复，不重跑旧任务 |

脚本会输出报告目录。`run.json` 中 `passed`、`restored` 都应为 `true`，`report.json` 各检查均应通过。记录清理用例只调整该用例生成的合成记录时间，不用真的等待 24 小时。容量满、清理未完成不能删除、配置越界等边界另由模块测试覆盖。

完整回归继续使用 `python3 scripts/run.py`，包含既有执行、隔离、网络、依赖构建和缓存验收，会重建本项目的动态环境缓存。

## 3. 查看恢复和清理

```bash
docker compose exec sandbox tail -F /run/sandbox_model/supervisor.log
docker compose exec sandbox tail -F /run/sandbox_model/service.log
docker compose exec sandbox docker ps -a --filter label=lazyx.sb=true
docker compose exec sandbox docker network ls --filter label=lazyx.sb=true
```

故障时能看到停止、恢复记录，结束后没有任务容器和任务网络。公共镜像和专用出网基础网络会保留。若清理失败，服务应保持未就绪，不能为了恢复接单而跳过残留检查。

## 4. 配置与使用边界

节点配置在 `deploy/settings.json`，修改后执行 `docker compose restart sandbox`。

- 正常模式默认通过固定公共 DoH 解析域名，严格验证证书；测试模式才使用合成 DNS。`dns_over_https=false` 时使用配置的公共 `dns_server`。
- 普通任务默认上传 8 MiB、下载 32 MiB，按转发的 TLS 字节统计，包含握手。任务字段 `network_upload_bytes`、`network_download_bytes` 可设更低额度；0 使用节点默认值。原网页内容 4 MiB 限制独立保留。
- 状态和重复提交记录默认保留 24 小时，最多 4096 条。达到上限返回 `HISTORY_FULL`；清理未完成的记录继续保留。超过保留期后不保证旧编号去重，提交新任务始终生成新 UUID。
- stdout、stderr 和结果文件仍只在内存中保留 180 秒；日志各最多两份、合计 2 MiB。节点重建会丢失内存内容，只有不含任务正文的历史状态和公共镜像保留。
- 故障后旧任务可能为 `unknown` 或 `failed`，不会自动重做；调用方先查询状态，再决定业务上是否另发新任务。
- 当前仍是已验收的 ARM64 Docker 运行环境。阿里云目标服务器验收、正式产品连接器接入不包含在这四项中。
